Why an event schedule needs a running-time check

An event slips a few minutes at a time: a speaker runs long, a changeover takes five minutes instead of two. On paper, the same thing happens when lengths are added up wrong. Chaining every Start to the row above's Ends, and checking the last end against the planned end, catches the error while there is still time to cut an item. It's time blocking for a whole team: every item gets its own block, and the blocks have to fit the evening.

The Owner, Location and Tech columns are what set this sheet apart from the time boxing template, which gives one person's tasks a box of minutes and a Done column.

How to write a run of show

  1. Fill in the header: event, date, venue, show caller, and the doors, start and planned end times.
  2. List every item in order, from doors to close. Include changeovers, walk-ins and breaks: they take time too.
  3. Give each item a length, an owner and a location, and note the mics, slides, music or lighting it needs.
  4. Chain the times. Write the first Start, add the Length to get Ends, and carry Ends down as the next row's Start.
  5. Run the check. Add up the lengths and compare the last Ends with the planned end. If you're over, cut or shorten something now.
  6. Share it with everyone named in the Owner column, and give the show caller a copy for the day.

Frequently asked questions

Is the run of show template free?

Yes. The run of show template PDF is completely free. There is no signup and no email required. Click the download link and print it.

What is a run of show?

A run of show is the minute-by-minute running order of an event: every item in order, when it starts, how long it takes, who owns it, where it happens and what the tech team needs. Everyone working the event reads from the same sheet.

Can I use it as an event schedule or conference schedule template?

Yes. For a conference, use one sheet per room or per day, with each talk as a row and the speaker as the owner. For a party, gala or launch, use one sheet for the whole event, from doors to close.

How does the running-time check work?

Each row has an Ends time, Start plus Length, which is the next row's Start. At the bottom, add up every row's length, break rows included, write the first start to the last end, and compare the last end with the planned end. If the show runs over, cut or shorten an item before the day, not during it.

How is it different from the time boxing template?

The time boxing template is one person's day: tasks with a box of minutes, a start, an end and a Done column for the actual minutes. The run of show is a landscape sheet for a team: every item has an owner, a location and tech notes, and the times chain into a running-time check against a planned end. For your own tasks, use the time boxing template.

Can I print it on US Letter paper?

Yes. The page is A4 landscape with wide margins, so it prints on US Letter too. Choose "Fit to page" in the print dialog if your printer adds its own margins.
