Time boxing vs. time blocking

Time boxing fixes how long a task may take: you give it 45 minutes and stop when they're up. Time blocking fixes when it happens, by putting it on the clock. Most people combine the two, which is why this worksheet has a Box column and Start and End columns side by side.

For a fixed routine whose steps add up to one leave-the-house time, use the morning routine checklist.

How to use a time boxing template

  1. List the tasks you want to finish today, one per row, most important first.
  2. Give each task a box. Write the minutes it may take, not the minutes you hope it takes. Add them up: if the boxes don't fit in your free hours, cut a task now rather than at 5 PM.
  3. Set a start and an end for every box, with short gaps between them.
  4. Stop when the box ends. Either the task is done, or you decide on purpose to give it another box. Tick Done and write the actual minutes.
  5. Total and review. Compare planned and actual minutes and note what to box differently tomorrow.
