Getting Started

Which devices does Align run on?

Align runs on iPhone and iPad with iOS or iPadOS 18.6 or later. It isn't available for Apple Watch or Mac.

What is time blocking?

A planning method where you give each task its own slot in your day. See Core Concepts.

Why does Align need full calendar access?

Align stores every time block as an event in your calendars, so it needs full access to show and save them. See Calendar Access.

Can I use my existing calendars?

Yes. Align shows events from the calendars on your device that you turn on, including iCloud, Google and Exchange calendars added in the Settings app. See Choose Which Calendars Appear in Align.

Can I use Align on more than one device?

Yes, when you use the same Apple Account on each device:

  • Time blocks are calendar events, so they sync through the calendar account they belong to, such as iCloud or Google. Set up the same calendars on each device.
  • Align's own data syncs through iCloud: each time block's icon, color and lock, its subtasks, completed time blocks, and your custom day start and end.
  • Other settings, such as overlap avoidance, appearance and notification defaults, stay on each device.

Time Blocks

How do repeating time blocks work?

Set a Recurrence in the editor to repeat a block daily, weekly, monthly or yearly. See Repeat a Time Block.

Can I change how a time block looks?

Yes. Each time block has a color and an icon. See Color and Icon.

Can I break a time block into smaller steps?

Yes, with subtasks (Align Plus). See Subtasks.

How do I get notified before a time block?

Add one or more alarms to the time block. See Alarms and Notifications.

Why did my notifications stop?

Align starts with quiet notifications, which are temporary. Allow full notifications to keep receiving them. See Notification Permission.

Arranging Your Day

What happens when time blocks overlap?

Blocks that share the same time are grouped into one card headed Overlapping time blocks. With overlap avoidance (Align Plus) turned on, nearby blocks shift when you drag or resize one so nothing overlaps. See Overlapping Time Blocks.

How do I see the latest changes from my calendars?

Pull down on the timeline. See Refreshing Your Calendars.

Account & Settings

Is Align free?

Yes. Align Plus is an optional subscription that adds more features. See Free vs Plus.

Where is my data stored?

Time blocks are stored in your calendars, and Align's own data in your iCloud account. See Where Your Data Is Stored.
