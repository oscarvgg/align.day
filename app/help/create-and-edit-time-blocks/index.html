Create and Edit a Time Block

Every time block in Align is an event in one of your calendars. You create and change time blocks in the time block editor, and you reach the most common actions from the selection menu on the timeline.

Create a Time Block

You can start a new time block in several ways. Each one opens the editor with the title New time block.

  • The + button: tap +. The block starts on the day you are viewing, at the current time. The button appears once Align has calendar access and at least one calendar is synced.
  • Free time on the timeline: tap Create time block in a gap between time blocks. On narrow layouts the button reads Create. The block starts when the gap starts.
  • An empty day: on a day with No time blocks, tap Create time block.
  • The New time block widget: add the New time block widget to your Home Screen or Lock Screen. Tapping it opens Align with a new time block that starts now.

A new time block is 15 minutes long until you change its end time.

To finish, tap Save (checkmark). Tap Cancel (X) to close the editor without saving.

The Editor

The editor shows its sections in this order: title and icon, Is all-day, Starts and Ends, Recurrence, Color, Calendar, Alarms, Subtasks and Notes. When you edit an existing time block, the editor is titled Edit time block and ends with Delete time block.

For the Subtasks section, see Subtasks.

Title and Time

  1. Type a title in the large field at the top.
  2. Tap Starts to show a picker for the start date and time. Tap Starts again to hide it.
  3. Tap Ends to set the end date and time.

While a picker is open, the editor shows the block's duration above it.

  • If you move the start after the end, the end moves to the same time. If you move the end before the start, the start moves with it.
  • Times are saved to the minute.
  • The time picker moves in steps of 5 minutes by default. To change the step, open Settings, then Time picker increments, and choose 1 minute, 5 minutes, 10 minutes, 15 minutes, 20 minutes or 30 minutes.

Is All-Day

Turn on Is all-day to make the time block last whole days. The Starts and Ends pickers then show only dates. Turn it off to set times again.

Calendar

Calendar shows the calendar the time block is saved to. Tap it to choose another calendar from Select a calendar.

  • A new time block starts in the calendar chosen in Settings > Default calendar: Default (the system's default calendar), Custom (a calendar you pick) or Last one used (the calendar you picked most recently in the editor).
  • If the selected calendar can't be changed, the editor shows This calendar is read-only. or This calendar doesn't allow adding or modifying time blocks below it. Choose a different calendar.
  • The Calendar section appears only when Align is set up to use your own calendars.

Color and Icon

  • Color: tap a color in the Color section to set the time block's color on the timeline.
  • Icon: tap the icon next to the title to open Select an icon. Use Search icons to find one; icons you chose recently appear under Recently used.

While you type the title of a new time block, Align suggests an icon that matches it. Once you pick an icon yourself, Align stops replacing it. Existing time blocks keep their icon. See Icon Suggestion for details.

Notes

Type any extra details in the Notes section. Notes also appear in the time block's selection menu.

Edit a Time Block

The Selection Menu

Tap a time block on the timeline to select it. A menu opens with the block's title, time and details, and these actions:

  • Edit: opens the editor for the time block.
  • Duplicate: opens a copy in a new editor. See Duplicate a Time Block.
  • Lock / Unlock: keeps the time block in place when you drag or resize other blocks. Locking requires Align Plus. See Locking Time Blocks.
  • Delete: deletes the time block. See Delete a Time Block.

To close the menu without choosing an action, tap an empty part of the screen.

Duplicate a Time Block

Duplicate opens the editor titled New time block with a copy of the time block. Nothing is created until you tap Save.

The copy keeps:

  • Title, icon and color
  • Start and end time, and Is all-day
  • Calendar
  • Recurrence
  • Alarms
  • Notes
  • Subtasks, all marked as not completed

The copy is never locked, even if the original is.

Delete a Time Block

You can delete a time block in two places:

  • In the editor, tap Delete time block at the bottom.
  • On the timeline, select the time block and tap Delete.

A time block that doesn't repeat is deleted right away.

For a repeating time block, Align asks: Are you sure you want to delete this time block? This is a repeating time block. Choose whether to delete only this occurrence or this and all future occurrences. See Repeat a Time Block.

Changes Made in Another App

While you edit an existing time block, Align watches for changes to the event in Calendar, on another device or through sync.

  • The event changed: fields you haven't edited update to the event's current values. Your own edits stay.
  • The event was deleted: Align shows This event was deleted in another app. Your changes can't be saved, and tapping OK closes the editor.
  • The event can't be found when you save: if the event was moved or deleted in another app, Align shows Couldn't find this event and doesn't save. Your edits stay in the editor. Close the editor and open the event again.
