Repeat a Time Block

A repeating time block shows up on your timeline on every day its schedule matches. Each appearance is an occurrence of the same series. Set the schedule once in the editor, then change a single occurrence or the whole series when your plans change.

Set Up a Repeating Time Block

  1. Open the editor for a new or existing time block.
  2. Go to the Recurrence section.
  3. Under Frequency, choose how often the time block repeats:
    • None: the time block doesn't repeat.
    • Daily: every day.
    • Weekly: every week, on the same weekday as the start date.
    • Monthly: every month, on the same day of the month as the start date.
    • Yearly: every year, on the same date as the start date.
  4. Tap Save.

Choosing a different Frequency starts the schedule over: any Advanced options and end you set before are cleared.

Advanced Options

Once you choose a Frequency other than None, the Advanced switch appears. Turn it on to set a more specific schedule and an end for the series. The options depend on the frequency.

When you turn Advanced on, Align fills in a starting point, so check the selected days or months before you save. Turning Advanced off goes back to the plain frequency, with no end.

Daily

  • Every N day(s): use the stepper to repeat every 2 days, every 3 days, and so on. Advanced starts at every 2 days.

Weekly

  • Every N week(s): use the stepper to repeat every 2 weeks, every 3 weeks, and so on.
  • On...: tap the days of the week the time block repeats on. You can select more than one day. A weekday is already selected when you turn Advanced on, so check that it's the one you want.

Monthly

Choose one of two modes at the top:

  • Each: tap the days of the month (1 to 31) the time block repeats on. You can select more than one day. A day is already selected when you turn Advanced on, so check that it's the one you want.

  • On the...: pick a position and a day, for example the first Monday or the last weekday of the month.

    • Position: First, Second, Third, Fourth, Fifth or Last.
    • Day: a day of the week (Sunday to Saturday), Day, Weekday or Weekend day.

    On the... starts at the first occurrence of the start date's weekday.

Yearly

  • Tap the months the time block repeats in. You can select more than one month. A month is already selected when you turn Advanced on, so check that it's the one you want.
  • Turn on Days of the week to repeat on a position and a day within those months instead, for example the last Friday of March. It uses the same position and day pickers as the monthly On the... mode.

End a Repeating Series

The Ends options appear below the Advanced options, so turn Advanced on to set an end. Without an end, the time block repeats indefinitely.

  • Never: the series has no end.
  • On Date: the series ends on the date you pick next to End date:. It starts at the time block's start date.
  • Occurrences: the series ends after a set number of occurrences. Use the After N times stepper to choose how many, from 1 to 999.

Edit One Occurrence or the Whole Series

When you save changes to a repeating time block in the editor, Align asks: This is a repeating time block.

  • Save for this occurence only: the change applies only to the occurrence you opened. The rest of the series stays as it was.
  • Save for future ocurrences: the change applies to the occurrence you opened and every occurrence after it. Earlier occurrences stay as they were.

The same question appears for an occurrence that was changed on its own before, even though it no longer follows the series' schedule.

New time blocks are saved right away, without this question.

Delete One Occurrence or the Whole Series

You can delete a time block from the editor with Delete time block, or from the timeline by selecting it and tapping Delete. For a repeating time block, Align asks: Are you sure you want to delete this time block? This is a repeating time block.

  • Delete this occurence only: removes only this occurrence. The rest of the series stays on your timeline.
  • Delete all future ocurrences: removes this occurrence and every occurrence after it. Earlier occurrences stay.

Deleting a time block from the timeline can be undone only when it doesn't repeat. Deleting a repeating time block can't be undone.

Move or Resize One Occurrence

Dragging or resizing an occurrence on the timeline changes only that occurrence. Align doesn't ask which occurrences to change, and the rest of the series keeps its time.

  • See Drag and Drop and Resizing Time Blocks for how to move and resize blocks.
  • To change the time of every future occurrence, open the time block in the editor, change Starts and Ends, and choose Save for future ocurrences.

Completion, Subtasks and Locks

  • Completion: each occurrence is completed on its own. Completing one occurrence doesn't complete the others. See Complete a Time Block.
  • Subtasks: each occurrence keeps its own subtask completion. When you save subtask changes with Save for future ocurrences, the new subtask list applies to this and every later occurrence. See Subtasks.
  • Locks: locking or unlocking an occurrence applies to that occurrence and the ones after it. Earlier occurrences keep their lock state. A later occurrence you moved or edited on its own earlier can keep its own lock state, so check it if it matters. See Locking Time Blocks.
